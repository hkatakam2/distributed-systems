Production Backend System Map

A compact map for reasoning about backend systems across companies and tools.

The Recurring Shape

IngressValidate request, authenticate caller, assign idempotency key, create trace context.
Durable factCommit the business event or transaction to a database, log, or outbox.
Async workFan out to consumers, workers, stream processors, and integrations.
Serving stateBuild queryable projections, caches, indexes, and read models.
OperationsObserve latency, errors, saturation, lag, correctness, and recovery behavior.

Core Problems

Problem Standard approaches Main tradeoff
Accept traffic safely Load balancers, rate limits, deadlines, backpressure, autoscaling Protecting the system can reject or delay valid work.
Remember facts durably Relational database, append-only log, outbox, replicated storage Stronger durability and consistency usually add latency and coordination.
Decouple producers and consumers Queues, logs, pub/sub, workflow engines Decoupling absorbs spikes but introduces lag, retries, and duplicate handling.
Serve reads quickly Caches, materialized views, denormalized tables, search indexes Fast reads often mean stale or duplicated state that must be reconciled.
Survive failure Retries, idempotency, DLQs, checkpoints, replication, reconciliation Recovery mechanisms can create duplicate effects or hide correctness bugs.
Debug production Logs, metrics, traces, exemplars, runbooks, SLOs More telemetry costs money and attention; poor telemetry creates blind spots.

Vocabulary

Event: a recorded fact that something happened, such as subscription_canceled.

Command: a request to do something, such as cancel_subscription.

Log: an ordered append-only sequence of records, often partitioned for scale.

Queue: a work-distribution structure where messages are usually consumed by one worker group.

Materialized view: precomputed read state derived from source facts.

Idempotency: making repeated attempts produce the same externally visible result.

Backpressure: slowing or rejecting upstream work when downstream capacity is constrained.

Lag: the distance between produced work and processed work.

Reconciliation: comparing derived state with source-of-truth state and repairing divergence.
